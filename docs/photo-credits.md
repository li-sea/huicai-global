## 许可要求速查

- **CC0 1.0**：可自由商用、修改、无需署名（图中两份仍已顺手署名，属礼貌做法）。
- **CC BY 2.0 / 3.0 / 4.0**：可商用、可修改，**必须署名**作者 + 许可 + 链接。
  网页页脚已放一行署名；若你把图片挪到 PPT、宣传册、社媒，请把这行署名一起带过去，或换成你们自己的实拍图后删除。
- 图片均**未做实质性改动**，仅按网页比例做了裁剪与压缩。

## 建议

1. **上线前最好是换成你们自己的实拍图**（工厂走访、装柜现场、团队合影、展会摊位），
   真实照片对成交率的帮助远大于图库图；换图后可以删掉页脚署名行。
2. 换图时保持同名同尺寸覆盖 `outputs/images/` 下文件即可，网页无需改动：

| 替换文件 | 建议尺寸 | 用在哪 |
| --- | --- | --- |
| `hero-port-night.jpg` | 1920×1080 | 首屏大图（越暗越好放白字） |
| `factory-line.jpg` | 1200×800 | 业务模块：中国商品代买 + 案例② |
| `team-meeting.jpg` | 960×640 | 业务模块：国际贸易服务咨询 |
| `warehouse-racks.jpg` | 1000×1250 | 业务模块：验厂验货 |
| `cranes-sunset.jpg` | 1600×1000 | 业务模块：跨境物流 + 案例③ |
| `yiwu-market.jpg` | 1600×900 | 行业深度横图 + 案例① |

3. 如果换成自己的照片，建议把首屏那张换成**你们团队在工厂/港口/展会现场的横图**，
   第一眼就能传达「我们真的在现场」。
